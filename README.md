A traffic jam explained to a 10-year-old in two lines: first as a school hallway full of cars all trying to squeeze through one classroom door at once, then an honest second line saying what that picture maps — the crowd and the one narrow door slowing everyone down — and what it leaves out, that cars cannot turn around and walk back like children can. The program in `main.ts` writes those two lines (247 characters) to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
